How the Jane Tool mechanism works

The platform uses a campaign cycle: collect support, confirm payment, register location, analyse messages, report progress, and protect supporter data.

1. Supporter Entry

Supporter opens website or later dials USSD and chooses Support, Register, Volunteer, or Send Message.

2. Contribution

Supporter chooses KSh 10, 20, 50, 100, 200, 300, 500, or Other and confirms using M-Pesa STK Push.

3. Data Capture

The system records name, phone, constituency, ward, consent, amount, transaction status, and time.

4. Analysis

Messages and notes are analysed to show repeated community themes such as water, youth, roads, health, education, and women empowerment.

5. Dashboard

Admin views totals, supporter growth, mobilizer activity, ward reports, messages, and exportable records.

6. Security

Private data is protected through login, role access, validation, audit logs, encryption, consent, and no public phone-number display.

Security Features

Security built into the live version

This prototype now includes a backend security plan and demo-ready structure. The live version must run on HTTPS with a real database and protected admin access.

Access Control

Admin login, strong passwords, bcrypt password hashing, role-based access for candidate, finance, coordinator, and viewer accounts.

Payment Protection

M-Pesa credentials stored in environment variables, secure callback URL, transaction status verification, and duplicate transaction checks.

Data Protection

Consent checkbox, minimal data collection, hidden public phone numbers, encrypted backups, and deletion/export procedures.

Attack Prevention

Input validation, output escaping, CSRF protection, rate limiting, secure cookies, HTTP security headers, and audit logs.
