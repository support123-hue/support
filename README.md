# Jane Tool Secure Version 2

This package contains a polished website prototype and a secure backend skeleton.

## Mechanism used
The tool follows the Obama-style campaign mechanism but replaces Obama with Jane:

1. Supporter entry through website and later USSD.
2. Small resource mobilization payments: KSh 10, 20, 50, 100, 200, 300, 500, and Other.
3. Supporter registration by constituency and ward.
4. Volunteer and mobilizer registration.
5. Supporter message collection.
6. Theme/word analysis for public concerns.
7. Private admin dashboard and reports.
8. Strong security controls for data and payments.

## Important
This is not yet a live payment system. It is a secure prototype and architecture package. Real money requires Safaricom Daraja credentials, Paybill/Till details, HTTPS hosting, database setup, and final security testing.
